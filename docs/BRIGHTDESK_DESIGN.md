# Brightdesk To Do — approved design brief

Follow the canonical [Brightdesk visual standard](https://github.com/connormolloy12/Brightdesk-suite/blob/main/docs/BRIGHTDESK_VISUAL_STANDARD.md) and [machine-readable design contract](https://github.com/connormolloy12/Brightdesk-suite/blob/main/docs/BRIGHTDESK_DESIGN_CONTRACT.json). Brightdesk-AI maintains a private mirror of the approved contract and injects it into development proposals and independent reviews.

## Shared shell

- Workspace canvas `#F3F6FA`; white work surfaces `#FFFFFF`; muted surface `#F8F9FB`.
- Deep navy navigation gradient `#14233F` to `#0D1930`, white primary labels and muted `#A8B6D0` secondary labels.
- Ink `#202B3C`, body text `#354256`, muted text `#68778C`, borders `#DFE4EC` and `#EBEFF4`.
- Inter/system sans-serif typography, consistent spacing/control sizes, restrained shadows and visible keyboard focus.

## To Do identity

- Approved accent `#27834F`; strong `#1D653C`; soft `#EDF7F0`.
- Original application icon `assets/branding/icons/to-do.svg`; approved concept preview `assets/previews/to-do.svg`.
- Use the accent for product actions and focus only. Keep shared surfaces consistent. Use original SVG artwork, never emoji, Unicode pictographs, initials or generic placeholders.

## Accessibility and evidence

Use semantic labels, keyboard-accessible controls, visible focus, sufficient contrast, non-colour status cues, reduced-motion support and responsive layouts without clipping essential controls. Concept artwork is not a screenshot; only publish screenshots captured from a current running desktop build after its workflow is checked.
