# Brightdesk To Do — product design brief

## Purpose
A simple local-first task manager for daily priorities, reminders and personal follow-through.

## Core experience
- My Day, Important, Planned and Completed views.
- Fast task entry with due date, priority and notes.
- Clear completed and outstanding states.
- Search and sort tasks.
- Keyboard and screen-reader-friendly interactions.

## Visual direction
Use the shared Brightdesk shell and a confident green To Do accent. Keep the daily list calm, uncluttered and easy to scan. Place a progress summary above the task list and make the main Add a task action obvious.

## Status
**Scaffold only.** This repository currently contains visual assets and a design brief; it does not yet contain runnable application source, a package manifest or a desktop build. The README preview is a design target, not an implemented screen.
